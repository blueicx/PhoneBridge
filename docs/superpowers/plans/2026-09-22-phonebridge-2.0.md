# PhoneBridge 2.0 全面增强实施计划

> **面向 AI 代理的工作者：** 每个批次必须先实现、测试、审查并独立提交；不得修改 `main`。手机实机验收延期，不能用历史 APK 或截图替代新版本验收。

**目标：** 在 `bed65d7` 基线上完成架构瘦身、AI 伴侣产品化、超大型现实探索内容包和个人侧载发布闭环。

**架构：** 统一使用 workspace timeline、revision、entityVersion 和 eventId。服务端按领域拆分路由与服务，Android 由 Repository/Coordinator 管理状态，视图只负责渲染。所有现实玩法离线可用，原图、精确坐标、轨迹和密钥永不进入持久化事件。

**技术栈：** Node.js 内置 HTTP/WS、现有运行时持久化、Kotlin/Room/WorkManager/CameraX/Vosk、现有 Canvas；可选 Ollama/llama.cpp 和 ARCore，不打包大型模型或外部地图。

## 批次 B：架构、模拟器与性能

- 拆分服务端入口和 Android 巨型状态协调器，保持历史 API 和 WebSocket 兼容。
- 增加开发/测试专用设备模拟器，覆盖 GPS 粗区域、线索、传感器、断线、电量、温度和帧率。
- Web 首屏 summary/懒加载/局部 DOM 更新；Android 延迟初始化相机、Vosk 和现实镜头，后台自动降频。
- 增加模块边界、模拟器和性能回归测试。

## 批次 C：AI 伴侣

- Provider 能力统一为文本、流式、离线、视觉、语音、工具和取消。
- 增加会话级 provider/model、流式 requestId、取消、超时、单次输出上限、重试和每日预算。
- 主 provider 失败只回退本地；备用联网 provider 不自动切换。
- 增加本地记忆检索、会话摘要、上下文压缩、记忆编辑/删除/导出和脱敏降级审计。
- 适度主动提醒默认每天最多 3 条，非紧急提醒冷却 2 小时，23:00–08:00 静默。

## 批次 D：现实探索与内容包

- 使用约 2 km 粗区域、时间桶和种子生成确定性事件；拒绝过期、跨区域、重复和异常高频结果。
- 三类线索、轻回合共鸣遭遇、实时手势加成和性格驱动自动模式全部支持离线。
- Canvas/传感器默认，ARCore 可用且温度/帧率正常时启用，否则自动回退。
- 新增 10 个 Mote，总数 20；40 个区域事件、20 种遭遇、40 件材料/道具、20 个配方、30 件装饰和 36 条任务。
- 加入库存、合成、装备、家园舒适度、图鉴、等级、增益和幂等奖励；运行时 schema 升级到 v3。

## 批次 E：个人侧载发布

- USB/localhost 默认连接；Wi-Fi 使用本机 TLS、证书指纹固定和五分钟一次性配对码/二维码。
- 增加首次启动向导、通知快捷动作、小组件、脱敏诊断导出、签名 APK、哈希、迁移和回滚清单。
- 版本提升到 `2.0.0` / `versionCode 2`；签名材料不进入仓库，禁止静默安装和商店自动发布。

## 验收

- 每批必须通过 Node 全量测试、Android `:app:testDebugUnitTest`、`assembleDebug`、性能预算、敏感扫描和 `git diff --check`。
- CI 必须在每个批次最新提交上通过。
- 实机恢复后另行验证 GPS、ARCore、三类线索、遭遇、文本/流式/PTT、通知、小组件、断线、温度、电量和长时间运行。
