# PhoneBridge 沉浸式个人伙伴扩充设计

日期：2026-09-22  
基线：`cfbdb2e` / `feature/integrated-enhancement`

## 目标

把 PhoneBridge 从“功能集合”收敛成一个打开即能使用的沉浸式个人伙伴：首屏只呈现 Mote、当前状态和最短交互入口；任务中枢、AI、现实探索、图鉴、诊断和节点设置仍然完整存在，但通过抽屉、手势、通知和深链进入。

## 已确认的入口行为

- 默认入口采用自适应策略：首次启动进入纯 Mote 伙伴层；只有上次明确使用现实镜头且相机权限仍有效时才恢复现实镜头。
- 启动时不主动请求相机、麦克风或定位权限；用户触发相应能力时按需请求。
- 沉浸层隐藏系统栏，保留一个短暂状态提示、Mote 反馈和聊天/按住说话入口。
- 上滑打开操作抽屉，长按 Mote 打开设置/诊断；返回键依次关闭键盘、抽屉、现实镜头和沉浸层。
- 离线时继续使用本地状态；联网恢复后通过现有 revision、eventId、outbox 语义同步。

## 功能闭环

### 入口与客户端

新增纯逻辑 `ImmersiveEntryPolicy`，只根据上次表面、相机使用记录、权限和节点状态返回启动表面，不直接产生 Android 副作用。`MainActivity` 只负责把策略结果映射到现有 Focus/Reality 视图，并通过 `WindowInsetsControllerCompat` 维持沉浸系统栏状态。

后续将把状态协调逐步下沉为 Repository/Coordinator：任务摘要、聊天上下文、提醒、健康、Mote 和现实探索由统一快照驱动，视图只消费快照和行为提示。

### AI 与任务

自然语言输入统一进入“草稿 → 待确认 → 执行 → 结果/失败”的任务状态机。Mote 只展示当前最相关任务；复杂详情、Provider、预算、审计和自治策略放到操作抽屉。主 Provider 失败只回退本地能力，备用联网 Provider 必须显式开启。

### Mote 与现实探索

关系等级、情绪、任务压力、设备健康和探索奖励统一输入 `MoteBehaviorEngine`。现实事件仍只使用粗区域和确定性种子；地点、物体、光线线索按 eventId 幂等，奖励进入库存/成长状态；Canvas 是默认实现，ARCore 只作为可选增强，不影响离线路径。

### 发布与质量

继续保持单用户、单节点、无云相册、无精确轨迹和无任意 Shell。补充 UI 自动化、模拟 GPS/相机/断网、迁移恢复、权限拒绝、性能和长期运行证据。签名发布只读取外部 keystore，不把签名材料写入仓库。

## 不做

本轮不增加多人、社交、在线地图、默认原图上传、连续精确轨迹、强制外部 AI、应用商店自动发布或完整 Compose 重写。
