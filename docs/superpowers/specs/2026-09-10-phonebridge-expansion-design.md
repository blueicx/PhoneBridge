# PhoneBridge 一体化扩充设计规格

日期：2026-09-10

## 目标

在 `feature/integrated-enhancement` 的 `cad00d0` 基线上，完成一轮可测试的任务执行、自治审批、离线同步、Mote 成长和交付质量增强。系统继续保持个人单用户、单 PhoneBridge 节点；手机实机验证延后。

## 已确认范围

1. 可中止、可重试、可观测的任务队列。
2. 有明确审批和租约边界的自治工具调用。
3. 带游标、缺口恢复和 ACK 语义的工作区同步。
4. Mote 关系、任务、行为和四种新形态的统一表现。
5. Web/Android 工作台一致性与 GitHub Actions 交付门禁。

## 设计边界

- `WorkspaceStore` 继续是任务、事件、自治策略、ActionRun 和审计的服务端真相源。
- 任务执行器通过依赖注入调用实际工作函数，测试使用可控 mock，不直接依赖手机或外部 AI。
- 事件使用 `eventId`、`origin + sequence` 和单调 `revision` 去重；无法安全增量恢复时回退全量快照。
- Android 以 Room 保存镜像和 outbox，WorkManager 只负责网络恢复后的可重入冲刷。
- Mote 的配置只保留一份跨端可映射的字段集合；Canvas 读取 `MoteBehaviorOutput`，不再按形态散落行为判断。
- 任意 Shell、删除、凭据、发布和其他不可逆操作永远硬禁止；白名单不能覆盖硬禁止。

## 批次与依赖

批次 1（同步协议）和批次 2（任务队列）先完成；批次 3（自治审批）依赖批次 2 的运行记录；批次 4（Mote）可并行但最终依赖新的任务状态事件；批次 5（客户端与 CI）收口全部服务端协议。

## 不在本轮

- 多人账号、多设备管理、外部 AI 服务和应用商店自动发布。
- 任何真实手机操作、ADB、相机线索点击、PTT 或物理崩溃验收。
- 修改 `main` 或发布令牌、运行时状态、凭据。
